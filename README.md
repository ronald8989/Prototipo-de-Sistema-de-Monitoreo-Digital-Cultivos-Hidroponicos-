# Prototipo de Sistema de Monitoreo Digital para Cultivos Hidropónicos
## Objetivo
El proyecto consiste en desarrollar un prototipo de escritorio para monitorear cultivos hidropónicos. El sistema permitirá visualizar datos de temperatura, humedad, pH y nivel de agua, además de controlar la bomba de riego y almacenar las mediciones para su posterior consulta.
## Entorno de programación
- Lenguaje: C#, Lenguaje de programación Arduino.
- Plataforma: .NET
- IDE: Visual Studio
- Base de datos: MariaDB / MySQL
- Administración de base de datos: MySQL Workbench
- Entorno local: XAMPP
- Hardware: Arduino y sensores
- Comunicación: Wi-Fi
El sistema será desarrollado como una aplicación de escritorio y estará conectado con el microcontrolador encargado de obtener las mediciones de los sensores.
